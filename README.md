# Роадмап — Мультиагентная система обзвона

Автономный офлайн-инструмент планирования (диаграмма Ганта) для выработки и сравнения
стратегий вывода мультиагентной системы обзвона клиентов на Q3.

Один самодостаточный HTML-файл — открывается двойным кликом в любом браузере,
без установки и без интернета. Данные хранятся локально в браузере (localStorage)
плюс экспорт/импорт JSON для бэкапа и передачи.

## Возможности

- **Несколько стратегий** во вкладках со сравнением сроков, трудозатрат и критического пути
  (бомж-вариант на заглушках vs целевой с интеграциями).
- **Диаграмма Ганта**: задачи, ответственные, сроки, вехи, прогресс; замороженная колонка
  имён и общий контейнер прокрутки (строки не разъезжаются).
- **Группировка** задач по разделам/процессам.
- **Автопланирование от зависимостей**: старт задачи = финиш позднейшего предшественника + 1 раб. день.
- **Критический путь** — подсветка задач без запаса хода.
- **Маркер дедлайна** квартала с подсветкой задач, вылезающих за срок.
- **Прямое редактирование**: перетаскивание баров (сдвиг по датам и изменение длительности).
- **Масштаб** день / неделя / месяц.

## Файлы

- `roadmap.html` — приложение.
- `roadmap - Copy.html` — резервная копия.

## Использование

Открыть `roadmap.html` в браузере. Кнопка **Экспорт** сохраняет состояние в JSON,
**Импорт** — восстанавливает. Клик по задаче — редактирование, перетаскивание бара — сдвиг сроков.
